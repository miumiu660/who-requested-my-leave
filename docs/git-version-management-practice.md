# Git 版本管理练习（2026-10-10）

这是一份独立的版本控制练习记录，不参与《谁替我请假》的游戏运行。

## 本次练习目标

1. 查看历史 Commit（提交记录）。
2. 从正式分支 `main` 创建练习分支 `practice/git-version-management-20261010`。
3. 仅在练习分支新增这份 Markdown 文档并提交一次 Commit。
4. 使用 Compare / Diff 查看与 `main` 的差异。
5. 创建 Draft Pull Request（草稿合并请求），**不合并**到 `main`。

## 术语

- **main**：正式分支，对应当前游戏项目的主要代码。
- **branch**：独立工作分支，可以先做改动而不修改 `main`。
- **commit**：给一组具体的文件修改留下有说明的记录。
- **diff**：比较两个版本之间哪些内容被增加、删除或修改。
- **Pull Request (PR)**：提交合并提议，供查看差异、讨论与审核；创建 PR 本身不会合并代码。
- **revert**：通过新增一次提交来撤销过去提交的效果。

## 安全约束

- 不改 `index.html`、`js/`、`css/` 或任何正式游戏资源。
- 不自动合并或发布游戏。
- 练习结束后可以保留本分支作为历史记录，也可以单独删除练习分支。
