# 谁替我请假

依据《谁请了我的假_Codex制作指令_v1.0.docx》实现的纯前端网页解谜游戏。公司、人物、七个异常日、年假与薪资数值、关键对话和四结局按设计文档实现。当前是可完整游玩的写实素材版。

## 运行

直接打开 `dist/index.html` 即可游玩，不需要安装依赖。建议通过静态网站或本地HTTP服务运行，以获得一致的附件下载、存档行为。进度保存在当前浏览器的 localStorage 中；换设备或换网址不会自动同步。

可选开发预览：在项目目录执行 `node scripts/dev-server.mjs`，默认端口4173。Node仅用于开发预览和测试，玩家无需安装。

## 已实现

- 游戏首页、公司工作台、企业通讯、OA、HR、财务、共享盘、本人确认。
- 四项在岗记录批量提交、两次群成员检索、四城票据归类、迁移操作日志、手动年假核算、薪资审批附件核对、代提模板首次记录追溯。
- 7个异常日：本月3、6、10、14、18、23、27日；28日开始调查。未解锁的消息和材料不会出现在正常游戏流程中。
- localStorage存档、重置、保留结局重新开始、结局回溯；《喵》标题页头像彩蛋。
- JPG附件预览与下载、真实DOCX附件、可下载的真实ZIP附件；所有资源均本地提供。
- 手机底部应用栏、聊天列表与会话切换、可横向滚动的表格、触控表单、键盘可操作的弹窗。

## GitHub Pages部署

1. 新建用于游戏的GitHub仓库。
2. 将 `dist` **里面的内容**上传到仓库根目录：确保根目录直接有 `index.html`、`css`、`js`、`assets`，不要再套一层 `dist`。
3. 进入仓库 Settings → Pages，在 Source 选择 Deploy from a branch，再选择 `main` 和 `/(root)`，保存。
4. 等待发布完成，使用GitHub Pages显示的地址打开。

配置依据：[GitHub官方发布源说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。无需后端、数据库、环境变量或构建步骤。所有资源使用相对路径，兼容仓库子路径。

## 素材替换

人物、中华田园橘猫及关键材料均已生成并写入本地素材。素材规则与可替换文件见 `dist/assets/README.md`；替换时不能改动远处残缺“何府”、36.6℃等证据。

## 验证

运行 `node tests/playthrough.cjs`。测试从空存档按顺序收集证据，验证错误选择与越级访问不能通关，再分别触发四个结局，检查年假/奖金数值、刷新恢复、重新开始、完整清除和本地资源存在性。

浏览器验收范围与记录见 `TEST_REPORT.md`。开发验收页仅由可选本地服务器通过 `/__qa/ui.html` 提供，正式部署目录中没有该页面或测试存档。
